Under the hood

Four passes between your photo and a room you would build.

01

Read pass

A segmentation model cuts the photo into regions, then a vision model names each one: sofa, door, window, wall, floor, walkway, clutter. Every region comes back with a bounding box.

02

Lock pass

Doors, windows and circulation are marked locked. Furniture, floor and clutter are marked editable. The locked regions are grown by a few pixels, because generators bleed across a hard edge and eat door frames.

03

Mask pass

The locked regions become an inpainting mask — white repaints, black is preserved. Where an editable sofa overlaps a locked window, the window wins. The mask is returned with the render so you can check the door really was protected.

04

Draw pass

Several options at once, differing only by seed, all constrained by the same mask. What changes between them is what the generator invents inside the editable area — never which parts of the room were allowed to move.
